# 🏥 HIMKIV Health & Clinical MedGuide

> **Intelligent Clinical Posology, Drug Salt Directory & Evidence-Based Dosage Advisory Portal**

---

## 🌟 Overview
**HIMKIV Health & Clinical MedGuide** is a modern, responsive web application engineered to provide clinical posology guidance, active pharmaceutical salt analysis, pediatric and adult dosage calculations (mg/kg), and clinical safety protocols.

Built with clean clinical UI/UX design tokens, zero external backend dependencies, and 100% client-side precision.

---

## 📑 Website Pages

1. **Home (`index.html`)**:
   - Universal search across conditions, active salts, and brand names.
   - 4-card clinical portal navigation with posology engine teaser.
   - Clinical workflow indicators and emergency triage banners.

2. **Clinical Survey (`survey.html`)**:
   - 3-Step interactive patient assessment wizard.
   - Real-time pediatric (mg/kg & syrup ml) and adult dosage calculations based on exact age and weight.
   - Comorbidity cross-checking and allergy red-flag warnings (e.g., Penicillin vs Amoxicillin).
   - Clean, print-ready prescription cards.

3. **Medicines & Salts Directory (`medicines.html`)**:
   - Instant filtering by therapeutic class (Pain/Fever, Antibiotics, Acidity, Allergy, Diabetes, Hypertension).
   - Deep search matching brand names, salts, and indications.
   - Comprehensive clinical monograph modal with indications, contraindications, and warnings.

4. **Dosage Calculator (`dosage-calculator.html`)**:
   - Posology simulation workbench with real-time sliders for age (months/years) and weight (kg).
   - Liquid suspension posology conversions (mg to ml based on syrup concentration).

5. **Clinical Safety & Protocols (`safety.html`)**:
   - Crucial medical safety rules (Paracetamol 4000mg ceiling, antibiotic resistance stewardship, pediatric measuring precision).
   - Red-flag triage checklist for emergency room (ER) visits.

## 🚀 How to Run Locally

Since this application is built with vanilla web technologies, no build steps (`npm install` or `build`) are required!

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari).

---

## 🌐 Deploy to GitHub Pages

1. Go to your repository settings on GitHub (**Settings** > **Pages**).
2. Under **Build and deployment** > **Branch**, select `main` (or `master`) and folder `/ (root)`.
3. Click **Save**.
4. Your website will be live at `https://<your-username>.github.io/<repo-name>/` in 1-2 minutes!
